# 📊 Customer Subscription & Churn Analytics

### Power BI Dashboard for Customer Retention, Subscription & Churn Analysis

This project is an interactive **Power BI dashboard** designed to analyze customer subscription behavior, engagement, feedback, and churn patterns.

The dashboard transforms raw customer subscription data into meaningful **business insights** that help organizations understand customer retention, identify high-churn subscription plans, analyze customer engagement, and improve retention strategies.

---

## 📌 Project Overview

Customer churn is one of the major challenges for subscription-based businesses. Understanding why customers leave and identifying high-risk customer segments can help businesses improve customer retention and overall customer lifetime value.

This project focuses on analyzing:

- 👥 Customer subscription behavior
- 📉 Customer churn and retention
- 📦 Subscription plan performance
- ⭐ Customer feedback and satisfaction
- 🔐 Customer engagement
- 🕐 Login activity
- 📅 Monthly subscription trends
- 🎯 High-risk customer segments

The final Power BI dashboard provides an interactive and easy-to-understand view of these metrics.

---

## 🎯 Business Objective

The main objective of this project is to provide businesses with actionable insights into customer churn and retention.

The dashboard helps businesses:

- Monitor customer churn and retention.
- Identify subscription plans with high churn rates.
- Understand customer engagement patterns.
- Analyze customer satisfaction through feedback scores.
- Identify potentially high-risk customer segments.
- Analyze customer activity and session behavior.
- Support data-driven customer retention strategies.
- Improve decision-making using interactive analytics.

## 🔄 Project Workflow

The dashboard was developed using a complete **Business Intelligence workflow**.

### 1️⃣ Data Preparation

Raw customer subscription data was cleaned and prepared for analysis.

The data preparation process included:

- Removing unnecessary data
- Handling missing values
- Checking data types
- Standardizing fields
- Preparing data for Power BI analysis

---

### 2️⃣ Data Transformation

**Power Query** was used to transform the dataset into an analysis-ready format.

Major transformations included:

- Data cleaning
- Column formatting
- Data type conversion
- Creating required calculated fields
- Preparing data for visualization

---

### 3️⃣ Data Modeling

The required customer, subscription, engagement, and churn fields were organized into a structured data model.

This helped ensure:

- Accurate calculations
- Reliable filtering
- Consistent KPI results
- Interactive dashboard performance

---

### 4️⃣ DAX Calculations

DAX measures were created to calculate important business KPIs.

Key metrics include:

- **Total Customers**
- **Active Customers**
- **Churned Customers**
- **Churn Rate %**
- **Average Feedback Score**
- **Average Days Since Last Login**
- **Total Sessions**

These measures provide a quick overview of customer health and subscription performance.

---

## 📊 Key Dashboard Metrics

### 👥 Total Customers

Displays the total number of customers available in the dataset.

### 🔴 Churned Customers

Shows the number of customers who have cancelled or discontinued their subscriptions.

### 📉 Churn Rate %

Measures the percentage of customers who have churned.
